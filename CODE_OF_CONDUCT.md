# Code of Conduct

Markdown Lens is an open-source project for people who want a useful, privacy-first Markdown viewer. Contributors and maintainers are expected to keep the project welcoming, respectful, and focused.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially with new contributors.
- Give feedback on the work, not the person.
- Keep discussions relevant to Markdown Lens and its community.
- Respect different experience levels and communication styles.

## Unacceptable Behavior

- Harassment, insults, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeatedly derailing issues or pull requests.
- Any behavior that makes participation unsafe or hostile.

## Reporting

If you see behavior that violates this Code of Conduct, please contact the project maintainer through GitHub. Reports will be reviewed and handled with care.

Maintainers may remove comments, close issues, block users, or take other appropriate action to protect the project community.
